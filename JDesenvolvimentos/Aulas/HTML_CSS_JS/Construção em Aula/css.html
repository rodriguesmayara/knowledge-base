CSS

Curso de CSS para Iniciantes

Aprenda a dar estilo às suas páginas web e transforme estruturas simples em layouts modernos, responsivos e visualmente atraentes. Neste curso, você vai dominar os principais conceitos de CSS e aplicá-los na prática em projetos reais.

Carga horária: 24 horas

Formato das aulas: aulas on-line gravadas, com exercícios práticos, desafios semanais e materiais de apoio para download

Nível: iniciante a intermediário

Pré-requisito: conhecimentos básicos de HTML

Certificado: disponível após a conclusão do curso e do projeto final

Conteúdo Programático

  • Introdução ao CSS e formas de aplicar estilos
  • Seletores, classes, IDs e especificidade
  • Cores, fontes e tipografia
  • Box model: margens, bordas, preenchimento e dimensões
  • Display, posicionamento e organização de elementos
  • Flexbox e CSS Grid para criação de layouts
  • Responsividade e media queries
  • Transições, animações e efeitos de hover
  • Boas práticas e organização do código
  • Projeto final: criação de uma página responsiva completa

Ao final, você terá desenvolvido uma página moderna e adaptável a diferentes dispositivos, estando preparado para avançar no estudo de JavaScript e criar interfaces mais dinâmicas.
