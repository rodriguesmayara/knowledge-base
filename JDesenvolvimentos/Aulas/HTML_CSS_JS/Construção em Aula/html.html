HTML

Curso de HTML para Iniciantes

Aprenda a criar páginas para a web do zero, mesmo sem experiência prévia em programação. Neste curso, você vai conhecer os principais elementos do HTML e praticar a construção de páginas organizadas e acessíveis.

Carga horária: 20 horas

Formato das aulas: aulas on-line gravadas, com atividades práticas e materiais de apoio para download

Nível: iniciante

Certificado: disponível após a conclusão do curso e das atividades

Conteúdo Programático

  • Introdução à internet e ao HTML
  • Títulos, parágrafos, listas e links
  • Imagens, tabelas e formulários
  • Elementos semânticos e acessibilidade
  • Projeto final: criação de uma página completa

Ao final, você terá desenvolvido uma página simples usando os conceitos aprendidos e estará pronto para continuar estudando CSS e JavaScript.
