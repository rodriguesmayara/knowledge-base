JavaScript

Curso de JavaScript para Iniciantes

Aprenda a dar vida às suas páginas web com interatividade e dinamismo. Neste curso, você vai conhecer os fundamentos da linguagem mais utilizada no desenvolvimento front-end e aplicá-los na criação de funcionalidades reais, como menus interativos, validação de formulários e consumo de dados externos.

Carga horária: 34 horas

Formato das aulas: aulas on-line gravadas, com exercícios práticos, desafios semanais, mini projetos e materiais de apoio para download

Nível: iniciante a intermediário

Pré-requisito: conhecimentos básicos de HTML e CSS

Certificado: disponível após a conclusão do curso e do projeto final

Conteúdo Programático

  • Introdução ao JavaScript e como executá-lo no navegador
  • Variáveis, tipos de dados e operadores
  • Estruturas condicionais e de repetição
  • Funções e escopo
  • Arrays e objetos
  • Manipulação do DOM e seleção de elementos
  • Eventos e interação com o usuário
  • Validação de formulários
  • Armazenamento local com localStorage
  • Assincronismo: Promises, async/await e consumo de APIs com fetch
  • Boas práticas, depuração e organização do código
  • Projeto final: criação de uma aplicação web interativa, como uma lista de tarefas ou um app de clima

Ao final, você terá desenvolvido uma aplicação web dinâmica e estará preparado para explorar bibliotecas e frameworks modernos, como React, e avançar na carreira de desenvolvimento front-end.
